# REDLINE 0.2.0 release notes

## What changed

REDLINE remains a single-owner local Windows writing assistant. The proofreading
selector is now labeled **Writing Context** and keeps its independent General,
Professional, and Academic choices.

**My Voice** adds optional, preview-first local rewriting with exactly three
lanes: Natural, Professional, and Academic. Select text, choose My Voice,
generate a local preview, then Accept or Cancel. Source text is never silently
overwritten. Existing selection mapping, stale-source refusal, protected-token
validation, formatting preservation, undo, autosave, and AXIOM reanalysis remain
in force.

This release also includes the verified 377-record local Terminology Engine,
the 290-case AXIOM floor, the coordination refactor, and responsive support down
to REDLINE's existing 720×480 minimum. The existing Tiptap editor packages were
updated together to security-patched 3.30.5 with the editor schema unchanged.

## Install and model options

REDLINE is distributed as an unsigned, private-use Windows x64 NSIS installer.
SmartScreen may warn. Normal installation is current-user and does not require
administrator access.

- The lightweight installer includes REDLINE and local dictation. Transform and
  My Voice remain disabled until the optional offline Qwen model package is
  installed.
- The bundled-model installer includes the same verified model and enables both
  Transform and My Voice without a separate model package.
- No downloader is included. The optional package is extracted into
  `%LOCALAPPDATA%\com.tyree.redline`, creating the expected `models` folder.

The app is runtime-offline. A machine without Microsoft Edge WebView2 Runtime
may need network access for Tauri's WebView2 installer bootstrapper; ordinary
REDLINE use does not.

## Privacy and security

- Documents, dictionary entries, Writing Context, and My Voice settings remain
  in the local SQLite database.
- Grammar, dictation, Transform, and My Voice use local providers only.
- No telemetry, updater, cloud inference, document upload, or model downloader
  is enabled.
- The production CSP and Permissions Policy remain local-only, and microphone
  access still requires the owner's explicit WebView2/Windows decision.
- Qwen and Whisper model identities are verified before provider use; raw
  document text and raw audio are not logged.

## Upgrades and uninstall

Normal upgrades preserve `%LOCALAPPDATA%\com.tyree.redline\redline.sqlite3`.
Installers produced since 0.1.0 retain downgrade protection. The historical
0.0.9 installer predates that guard and can overwrite a newer installation if
deliberately rerun.

Normal uninstall preserves local application data. The optional unchecked
delete-data choice permanently removes REDLINE application data. Recovery
history remains a bounded local convenience, not an off-device backup, and the
SQLite database is not encrypted at rest.

## Known limitations

- The small local Qwen model can make conservative wording substitutions. My
  Voice therefore remains preview-first and user-approved.
- High-confidence prompt-like source is refused instead of rewritten.
- Academic results that introduce measured grandiose phrasing are refused with
  the source unchanged.
- The app does not learn the owner's style automatically and does not yet expose
  editable voice traits.
- **Live Dictation 2.0 remains deferred.** Production dictation remains the
  existing record → stop → local transcription → insert workflow.
