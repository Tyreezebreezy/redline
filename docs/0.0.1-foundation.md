# REDLINE 0.0.1 foundation

## Architecture

REDLINE 0.0.1 is one root-level application: a React and TypeScript interface bundled by Vite inside a Tauri 2 Windows shell. `App.tsx` composes stable semantic regions; `AppShell.tsx` owns their presentational markup; `ThemeControl.tsx` owns the only interactive state in this milestone.

There is no multi-package workspace or reusable package yet. `pnpm-workspace.yaml` contains only pnpm 11's required per-project build-script allowlist; it declares no package globs. A multi-package workspace becomes useful only when AXIOM or another genuine shared package exists.

## Data flow

The frontend does not call Rust. The only state is the appearance choice (`dark`, `light`, or `system`), stored in WebView `localStorage`. System mode observes `prefers-color-scheme`. No writing or document data exists.

## Security boundary

- All application assets are bundled locally.
- No Tauri commands or plugins are registered.
- The main WebView has an explicit empty capability list, so it has no IPC authority.
- No filesystem, shell, process, microphone, camera, network, or updater permission is enabled.
- Production CSP is local-only and denies connections.
- Development CSP adds only the fixed loopback Vite HTTP and WebSocket origins required for hot reload.

## Deferred

AXIOM, a real editor, documents, persistence, autosave, grammar and spelling checks, scores, suggestions, voice, transformations, synchronization, accounts, servers, telemetry, and mobile work are outside 0.0.1.
