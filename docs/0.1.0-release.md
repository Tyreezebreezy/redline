# REDLINE 0.1.0 release notes

## Install and first run

REDLINE is distributed as a current-user NSIS installer. It creates a Start Menu entry and does not require administrator access for normal installation. The private release is unsigned, so Windows SmartScreen may show an unrecognized-app warning. Only install a package received from the REDLINE owner and verify its published hash before continuing.

REDLINE is runtime-offline: proofreading, dictation, Transform, and document storage do not use a remote service. The installer keeps Tauri's `downloadBootstrapper` WebView2 mode. Installation may therefore require internet access on a machine that does not already have Microsoft Edge WebView2 Runtime; ordinary use after installation does not.

## Optional offline Transform

The default installer stays small by excluding the Qwen Transform model. Extract the separately supplied Transform package into:

`%LOCALAPPDATA%\com.tyree.redline`

The expected file is:

`%LOCALAPPDATA%\com.tyree.redline\models\qwen2.5-1.5b-instruct-q4_k_m.gguf`

Transform remains unavailable when the model is absent, and generation is blocked before model initialization if the pinned SHA-256 verification fails. REDLINE provides no downloader and makes no network request to obtain it. The optional package includes its own README, model identity, byte count, source, license, and hash.

## Microphone permission

REDLINE asks through WebView2 before using the microphone and never grants itself access silently. If access is denied, confirm **Windows Settings → Privacy & security → Microphone → Let desktop apps access your microphone**, close REDLINE, and reopen it. If WebView2 still remembers a denial, close REDLINE and rename `%LOCALAPPDATA%\com.tyree.redline\EBWebView`; documents remain in the separate SQLite database.

Audio is held in bounded memory, sent only to the bundled local Whisper provider, and discarded after stop, cancel, failure, or the 90-second limit. No recording is written to disk.

## Documents, upgrades, and uninstall

Documents, recovery points, profiles, and dictionary terms are stored locally in `%LOCALAPPDATA%\com.tyree.redline\redline.sqlite3`. Normal upgrades preserve that data. Installers produced for 0.1.0 and later block silent downgrades. The historical 0.0.9 installer predates that guard and can overwrite 0.1.0 if it is deliberately run again.

Normal uninstall preserves REDLINE application data so reinstalling can recover it. The uninstaller's optional, unchecked delete-data choice removes the entire REDLINE application-data directory. That removal is permanent; export or back up anything important first.

REDLINE recovery history is bounded local convenience, not a backup system. The SQLite database is not encrypted at rest in 0.1.0.

## Privacy and security boundary

- No cloud inference, telemetry, updater service, shell command, general filesystem authority, or arbitrary networking is enabled.
- Tauri commands are limited to document lifecycle, personal dictionary, dictation lifecycle, and local Transform lifecycle operations.
- Production CSP and Permissions Policy remain local-only and microphone access is restricted to the app's own origin.
- Model hashes are verified before provider initialization and valid models are reused for the process lifetime.
- Raw document text and raw audio are not logged.

Production dependency and model license metadata is bundled as `THIRD_PARTY_NOTICES.txt`.
