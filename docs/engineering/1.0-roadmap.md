# REDLINE 1.0 roadmap

This is sequencing guidance, not a promise to renumber current releases.

## Stable base

- 0.1.1: preserve the verified daily-use baseline and release it separately if
  the owner chooses.
- Foundation checkpoint: Dictation 2.0 remains paused pending its laptop
  live-microphone gate.
- Working branch: the behavior-preserving coordination refactor and production
  Terminology Engine are complete pending final checkpoint verification.

## Evidence-led phases

1. Architecture cleanup: completed by extracting only editor construction,
   Transform coordination, and Tauri startup/command registration.
2. Terminology Engine: completed with a reviewed 377-record offline snapshot,
   deterministic generation, ambiguity controls, and validation.
3. Single-owner preferences: completed for the current My Voice enablement and
   default lane. REDLINE has no Guest, account, named profile, or user switch.
4. Humanizer/Voice: implemented as optional preview-first suggestions for
   Natural, Professional, and Academic lanes; never silent rewriting.
5. Clarity: advisory wordiness, repetition, passive voice, awkwardness, and
   flow, semantically separate from AXIOM.
6. Word Tools: explicit on-demand vocabulary actions; valid vocabulary is not
   a grammar error.
7. Tone: reader-perception analysis with confidence, never correctness.
8. Writing Goals: small explicit audience, purpose, and formality context.
9. Dictation 2.0: deferred until the hybrid experiment passes latency,
   accuracy, memory, live-edit, laptop microphone, and packaged-security gates.
10. Transform Studio: preview-first practical transformations with existing
   local safety boundaries.
11. Style Guide: scoped preferred and discouraged forms layered above built-in
   terminology.
12. Snippets: owner-local explicit expansions.
13. Final integration and polish: cross-feature focus, undo, persistence,
   preference, long-document, responsive, privacy, and resource regression.
14. 1.0: stable, complete, local-first writing workbench.

## Deferred beyond this foundation

Reader Impact, citations/research assistance, plagiarism or AI detection,
multilingual grammar, extensions, mobile input, system-wide overlays,
collaboration, analytics, cloud grammar/dictation, and server sync remain
unapproved.

## Next bounded decision

Complete the stable Humanizer release first. Clarity and Word Tools may begin
only afterward on a new branch; do not start Tone or another Dictation
experiment in parallel.
